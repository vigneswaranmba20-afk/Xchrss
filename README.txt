VER CHESS INTELLIGENCE — VERSION 2

NEW:
- Lichess-default Cburnett chess-piece SVGs (online); fallback glyphs when images fail.
- Green arrow shows Stockfish preferred move, red arrow shows the move played.
- Comparison automatically appears at engine-identified mistakes / blunders / missed opportunities.
- Arrows ON/OFF switch and before/after toggle.
- Existing PGN importer, move navigation, Stockfish evaluation and copyright notice preserved.

GITHUB PAGES UPDATE (Android):
1. Extract this ZIP.
2. In your Xchrss repository, replace the root index.html with this file; commit changes.
3. Add COPYRIGHT.md to your repository for third-party chess-piece attribution.
4. Open your website over HTTPS. Analyze a completed game, then tap a flagged move to see both arrows.

IMPORTANT:
- Green/red arrows only display once a game was analyzed and a stronger alternative exists.
- This app needs internet to load Stockfish and the Lichess piece artwork; piece fallback works offline.
- SVG chess pieces are third-party GPLv2+ artwork, not included in proprietary copyright claim.
